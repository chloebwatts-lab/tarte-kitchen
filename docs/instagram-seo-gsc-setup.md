# Instagram as an SEO channel — GSC setup + post playbook

Context: Google Search Console launched **platform properties** (announced 7 July 2026).
You can now add @tartebakery as its own property in Search Console and see which
Google searches surface our Instagram posts — the same way we track tarte.com.au.
Google is increasingly ranking Instagram posts directly in Search results, so
captions now double as search copy.

## One-time setup (~5 min, do on desktop)

1. Open [Google Search Console](https://search.google.com/search-console) with the
   account that owns the tarte.com.au property.
2. Property dropdown (top left) → **Add property** → choose **Instagram**.
3. Follow the prompts to authorise with the @tartebakery login.
4. Done — Performance / Insights / Achievements reports appear for the profile.

Note: the feature is rolling out gradually through July–August 2026. If Instagram
doesn't appear as a property type yet, check back in a few days — nothing is wrong
with the account.

Optional while in there: add TikTok/X/YouTube if we ever post there. Facebook and
LinkedIn aren't supported yet.

## What changes about how we write posts

Google indexes the caption, alt text, and text on the first slide. Treat the first
line of every caption like a page title.

- **First line = what someone would Google.** "Almond croissants in Burleigh Heads"
  beats "Saturday mood ☀️". Emojis and vibe copy can follow after.
- **Name the venue and suburb in words** — "Tarte Bakery, Burleigh Heads" /
  "Tarte Beach House, Currumbin" — not just the geotag.
- **Write alt text on every image** (Advanced settings → alt text): plain
  description + product + suburb.
- **Put real words on slide 1** of carousels — text in the image is indexed.
- **Say the product by its searchable name** at least once: croissant, cruller,
  brunch, specialty coffee — not just a nickname.

Search phrases worth owning (use naturally, one or two per post):
`best croissants gold coast` · `burleigh heads bakery` · `currumbin brunch` ·
`bakery near burleigh beach` · `gold coast pastries` · `specialty coffee burleigh`

## Caption template

```
[Product] at Tarte Bakery, Burleigh Heads — [one-line hook].

[1–2 sentences of normal voice: what it is, when it's fresh, why we love it.]

Open from 6:30am daily · 1748 Gold Coast Hwy, Burleigh Heads
Also at Tarte Beach House, Currumbin.

#goldcoastbakery #burleighheads #[product]goldcoast
```
